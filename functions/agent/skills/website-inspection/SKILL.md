# Website Inspection

## Purpose
Guide an inspection of a website supplied by the user, using only evidence
returned by an enabled website-inspection tool.

## Activate when
The task asks to inspect, review, audit, or evaluate a supplied website and
website evidence is needed to answer it.

## Instructions
- Consider messaging, page structure, navigation, calls to action, trust
  signals, accessibility cues, and other elements relevant to the user's goal.
- Separate directly observed facts from assumptions or recommendations.
- Cite or describe only details present in tool output.
- If the tool returns mock data or no page evidence, explain that a genuine
  inspection is not possible.

## Expected inputs
The user's objective, any submitted business name and URL, and actual tool
results for that site.

## Limitations
Do not infer site content from its URL or business name. Do not claim a page was
visited without actual fetched evidence. The current mock tool fetches nothing.
