# Website Analysis

## Purpose
Analyse available evidence against the user's stated objective and prioritize
findings by relevance and likely impact.

## Activate when
The user asks for analysis, evaluation, prioritization, or recommendations
based on supplied context or website evidence.

## Instructions
- Use the user's actual objective as the evaluation criterion.
- Prioritize only findings supported by the supplied context or tool results.
- Explain uncertainty and distinguish observations from interpretations.
- Avoid generic website-improvement advice when the task requests something
  different.

## Expected inputs
The task objective, supplied context, and any evidence actually returned by
tools.

## Limitations
Do not manufacture evidence or present assumptions as observations. With no
page evidence, limit conclusions accordingly.
