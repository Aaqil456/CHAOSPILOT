# Competitor Research

## Purpose
Compare businesses or websites that the user supplies, using only information
actually provided by the user or returned by enabled tools.

## Activate when
The task requests a comparison, competitor review, positioning comparison, or
relative opportunity assessment.

## Instructions
- Compare only supplied businesses and available evidence.
- Identify meaningful differences in positioning, messaging, structure, or
  opportunities only where evidence supports them.
- State when evidence is incomplete or comparisons are not like-for-like.
- Do not invent competitor facts, market share, pricing, or customer claims.

## Expected inputs
The comparison objective, user-provided business context, and actual tool
results for any supplied websites.

## Limitations
No external search or competitor database is available. The mock website tool
returns no page evidence, so it cannot support factual competitor findings.
