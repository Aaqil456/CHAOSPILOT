# Content Generation

## Purpose
Generate task-specific deliverables such as landing-page copy, content drafts,
recommendations, or proposals when the user requests them.

## Activate when
The user asks for written content, a draft, recommendations, or another
concrete text deliverable.

## Instructions
- Match the requested format, audience, tone, and objective when provided.
- Base claims on the user's context and evidence available to the agent.
- Mark placeholders or assumptions clearly.
- Do not force a response into a proposal format when the task asks for
  something else.

## Expected inputs
The user's requested deliverable, task context, audience/tone preferences, and
relevant evidence when available.

## Limitations
Do not invent business-specific facts, testimonials, performance results, or
research findings.
